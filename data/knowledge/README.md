# 상담 지식 문서 (knowledge MCP 서버)

`knowledge` MCP 서버의 `search_terms` 도구가 검색하는 문서입니다. AvengersBank는 시연용 가상 은행이므로 **모든 약관·수치는 가상**입니다.

- `products/`: 상품별 약관 요약 (상품 이름은 `data/seed/products.json`과 같아야 합니다)
- `faq/`: 이체·보안·앱 이용 FAQ

쓰는 규칙
- 파일 첫 줄 `# 제목`은 문서 이름, `## 소제목` 하나가 검색 단위(조각) 하나입니다. 조각은 짧고 한 가지 주제만 담습니다.
- 앱에 없는 기능(지점 방문, 고객센터 전화, 해지 버튼 등)을 있는 것처럼 쓰지 않습니다. 에이전트가 이 문서를 근거로 답합니다.
- FDS(이상거래 탐지)의 판정 기준값(금액, 시간대, 규칙 목록)은 쓰지 않습니다. 사기범이 기준을 피해 가는 데 쓸 수 있습니다.
- 이 README는 검색 대상이 아닙니다.
- `products/*.md`는 **가입 화면의 이용약관**이기도 합니다. 파일 내용 해시가 약관 버전이라, 고치면 버전이 바뀌고 예전 버전으로 온 가입 요청은 `TERMS_NOT_AGREED`로 거절됩니다 (화면이 새 약관을 다시 보여 줌). 상품 이름은 제목에 그대로 둡니다.
