# 발표 자료 초안 (슬라이드별)

15분 발표 기준 (발표 8분 + 시연 7분). 숫자는 모두 이 저장소의 결과 문서에서 가져왔다. 슬라이드 파일로 만들 때 이 순서를 쓴다.

---

**1. 제목**
AvengersBank — 말로 하는 은행, 속지 않는 은행
AUI 에이전트 + 이상거래 탐지(FDS) + 음성 인증

**2. 문제**
- 모바일 뱅킹은 메뉴가 깊다. 이체 한 번에 화면 6~7개 → 고령층·디지털 취약계층이 어렵다
- "엄마한테 5만원 보내줘"로 끝나는 AUI(Agentic UI)가 답이 될 수 있다
- 하지만 AI가 대신 실행하면 새 위험이 생긴다: 보이스피싱에 속은 사용자의 지시, 계정 탈취, 프롬프트 인젝션

**3. 목표: 편리함과 안전을 한 세트로**
- 말로 조회·이체·상품 상담·카드 발급
- 돈이 움직이기 직전에는 반드시 사람의 확인 + FDS
- 고령층: 큰 글자, 음성 안내 기본 켜짐, 경고는 소리로

**4. 구조** ([MCP_SERVERS.md](MCP_SERVERS.md) 그림)
React(음성) → FastAPI → LangGraph 에이전트 → MCP 서버 6개(계좌·이체·상품·카드·보안·상담 지식, 도구 26개) → 은행 서비스
이체 실행은 별도 경로: 확인 카드 → 승인(목소리·PIN) → FDS → 실행

**5. AUI 에이전트의 안전 장치**
- LLM은 의도와 슬롯만 뽑는다. 금액은 정규식으로 다시 계산해 다르면 되묻는다 ("오만원" vs 50만원)
- 이체 실행 도구는 LLM에게 없다. 확인 카드 토큰: 5분, 대화당 최신 1장, 한 번만
- 붙여넣은 문자 속 지시는 명령이 아니다 (실제 Gemini로 확인)
- MCP: 수취인 등록·이체 카드 도구는 LLM 제외, 한도는 낮추기만, 변경은 동의 후

**6. FDS: 규칙 + LightGBM** ([results.md](../fds_training/results.md))
- 규칙 8개 (1회·1일 한도, 신규 수취인 고액, 심야 고액, 새 기기, 잔액 소진, 차단 후 재시도, 대화 속 보이스피싱 표현) + AI 대화 판별(키워드 없이 돌려 말하는 가족 사칭·대출 사기도 잡음). MEDIUM 3개면 HIGH
- LightGBM 21개 피처 (평소 대비 금액·시간대, 수취인 이력, 속도, 세션)
- 합성 데이터: 500명 × 3개월, 14,712건, 사기 3종 1.4%
- 검증 PR-AUC 0.98 — **합성 데이터라 실제보다 높다**. 그래서 규칙이 1차 방어
- 판정: LOW 통과 / MEDIUM PIN / HIGH 차단 + 경고 음성

**7. 왜 막혔는지 설명 (SHAP)**
- SHAP 상위 요인: 처음 보내는 계좌, 시간대, 잔액 대비 비율, 세션 내 시도 횟수
- 차단 화면에 규칙 이름 + AI 근거를 같이 보여 준다
- (그림: `fds_training/results/shap_summary_dot.png`)

**8. 음성: 입력·안내·승인** ([VOICE_AUTH.md](VOICE_AUTH.md))
- STT → 되읽고 "확인"하면 전송 (오인식 방지)
- 승인: "확인 + 무작위 숫자 3개" → 서버가 숫자(Gemini)와 목소리(ECAPA 화자 임베딩)를 확인
- 무작위 숫자 = 녹음 재생 공격 방지. 2번 실패하면 PIN
- 목소리 특징은 민감정보: 동의, 암호화, 원본 미저장, 삭제 가능

**9. 시연** ([DEMO.md](DEMO.md))
1 음성 이체 → 2 PIN → 3 보이스피싱 차단 → 4 이유 → 5 다른 목소리 → 6 MCP

**10. 결과**
- REST API 39개, MCP 도구 23개, 테스트 136건 통과
- 시연 시나리오 자동 점검 7/7 (`scripts/demo_check.py`, 실제 Gemini)
- 응답: 이체 대화 약 2초, 조회 답변 5~12초

**11. 한계와 다음 단계** (솔직하게)
- FDS: 실제 사기 데이터가 아닌 합성 데이터. 요일 피처 과적합 흔적
- 화자 인증: 합성 음성 기준 같은 성별 타인 통과 16.7% → 실제 목소리로 기준값 보정 필요. 속은 본인과 실시간 음성 복제는 못 막는다
- 변경 도구의 "동의 후 실행"은 프롬프트 규칙 → 돈이 움직이는 도구는 아예 주지 않는 것으로 보완
- 다음: 실제 사용자 테스트(고령층), RAG 상품 상담, 서버 STT 폴백

**12. 마무리**
